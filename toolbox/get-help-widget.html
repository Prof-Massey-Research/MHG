Appendix 5.6 · Copy-paste code

Website "Get Help" Widget

A self-contained block of HTML you can paste into your program's website to give crisis resources a permanent, obvious home.

Supports Guideline 06 — Locating Resources & Services

Read the guideline

What this is

A ready-made "Get Help Now" block for your program's website. It has no dependencies — no JavaScript, no external stylesheets, no fonts to load — so it can be pasted into almost any site builder, CMS or hand-written page and will render correctly.

Before you paste it

  • Replace [LOCAL RESOURCES URL] with a link to your own directory page.
  • Replace [POINT PERSON NAME] and [POINT PERSON EMAIL].
  • Put the block somewhere persistent — a footer, a sidebar, or a dedicated page linked from your main navigation. A resource nobody can find does no work.
  • Check the phone links work on mobile after you publish.

Adding a QR code

Athletes often prefer to scan rather than type. Generate a QR code pointing at your resources page and place it next to this widget, on your bathroom stall posters, and in preseason packets. Point the code at a page on your own domain so you can update the destination later without reprinting anything.

Accessibility notes

  • The block uses real links, so screen readers announce each resource and its number.
  • Phone and SMS links work on mobile devices and are ignored gracefully on desktop.
  • Colors meet WCAG AA contrast in both light and dark mode.
  • Do not replace the text with an image — images of phone numbers cannot be read aloud, copied or dialed.
